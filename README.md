# 彭城七里 · 徐州旅游攻略 NFC互动网页

## 项目说明

这是为"彭城七里"文创手指陀螺项目配套的 **NFC 互动手机网页**。手机触碰手指陀螺上的 NFC 标签后，自动打开徐州旅游攻略。

## 文件结构

```
彭城七里徐州旅游攻略/
├── index.html      # 主页面（旅游攻略网页 + NFC欢迎遮罩）
├── nfc-start.html  # NFC触碰启动页（信号动画 + 设备检测）
└── README.md       # 本说明文档
```

## 功能特性

### 📡 NFC 一碰即开
- **nfc-start.html**：NFC 标签触发后的启动页
  - 显示 NFC 信号波纹动画
  - 自动检测设备类型（iPhone/Android）
  - 支持 Web NFC API（Android 可读取标签内容）
  - 3秒后自动跳转主页面
  - 双击模拟 NFC 触发（开发测试用）

- **index.html**：主旅游攻略页面
  - 绿色渐变 NFC 欢迎遮罩（带波纹动画）
  - NFC 信息提示栏
  - 自动检测是否从 NFC 启动

## 打包与分发

### 方式一：本地离线使用
将整个文件夹打包发送给好友，解压后在浏览器中打开 `index.html`。

### 方式二：上传服务器（推荐）
上传到 Web 服务器后，将 URL 写入 NFC 标签：
```
https://your-server.com/彭城七里徐州旅游攻略/nfc-start.html
```

### 方式三：GitHub Pages 免费托管
1. 创建 GitHub 仓库
2. 上传项目文件夹
3. 开启 GitHub Pages
4. 将 Pages URL 写入 NFC 标签

## NFC 标签配置

### 推荐标签型号
- **NTAG213**（144字节）- 最便宜，适合纯 URL
- **NTAG214**（504字节）- 性价比最高，推荐
- **NTAG215**（888字节）- 容量大，支持更多数据

### 写入步骤
1. 手机下载 "NFC Tools" APP
2. 选择 "Write" → "Add a record" → "URL"
3. 输入网页地址：`https://your-server.com/nfc-start.html`
4. 将标签贴在手指陀螺底部
5. 点击 "Write" 写入标签

### 不同平台的 NFC 行为
| 平台 | 行为 |
|------|------|
| iOS 13+ | 触碰标签自动打开 Safari 访问网页 |
| Android 10+ | 触碰标签自动打开浏览器 |
| Android（Web NFC） | 可读取标签内容，支持更多交互 |

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript，零外部依赖
- 响应式设计，适配所有手机端
- 单文件架构，便于分发
- 支持 Service Worker（可扩展为 PWA）

## 修改建议

### 替换真实景点照片
将 `index.html` 中的图片 URL 替换为本地路径：
```html
<!-- 替换前 -->
<img src="https://images.unsplash.com/..." alt="云龙湖">

<!-- 替换后 -->
<img src="images/yunlong-lake.jpg" alt="云龙湖">
```

### 添加自己的 NFC 标签内容
修改 `nfc-start.html` 中的跳转逻辑，可添加标签ID验证等。

### 扩展为 PWA
添加 `manifest.json` 和 `service-worker.js` 可实现：
- 离线访问
- 添加到主屏幕
- 推送通知
